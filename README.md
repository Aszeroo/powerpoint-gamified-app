# PowerPoint Gamified App

เว็บแอปพลิเคชันเกมมิฟิเคชันสำหรับฝึกทักษะการใช้งาน Microsoft PowerPoint ออกแบบมาสำหรับนักเรียนระดับประกาศนียบัตรวิชาชีพชั้นปีที่ 2 (เทียบเท่า ปวช.2) เพื่อเพิ่มแรงจูงใจและประสิทธิภาพในการเรียนรู้ผ่านกลไกเกม เช่น ระบบคะแนน ประสบการณ์ (XP) เลเวล รางวัล และกระดานผู้นำ

## ภาพรวมโครงการ

โครงการนี้เป็นเว็บแอปพลิเคชันที่ใช้เทคโนโลยีสมัยใหม่เพื่อสร้างประสบการณ์การเรียนรู้ทักษะ PowerPoint ที่น่าสนใจและมีปฏิสัมพันธ์ ด้วยการผสมผสานองค์ประกอบของเกมมิฟิเคชันเข้ากับเนื้อหาการเรียนรู้ ทำให้ผู้เรียนสามารถติดตามความก้าวหน้า ได้รับรางวัลจากการทำกิจกรรมสำเร็จ และแข่งขันอย่างเป็นมิตรกับเพื่อนร่วมชั้นผ่านกระดานผู้นำ

## คุณสมบัติหลัก

### ระบบเกมมิฟิเคชัน
- **ระบบคะแนนและ XP**: ได้รับคะแนนเมื่อทำบทเรียนหรือความท้าทายสำเร็จ
- **ระบบเลเวล**: เพิ่มเลเวลเมื่อสะสมคะแนนถึงเกณฑ์ที่กำหนด
- **ระบบรางวัล**: ได้รับแบดจ์และรางวัลพิเศษเมื่อบรรลุเป้าหมายเฉพาะ
- **กระดานผู้นำ**: แสดงอันดับผู้เรียนตามคะแนนรวม
- **ระบบความต่อเนื่อง (Streak)**: ให้รางวัลพิเศษเมื่อเรียนต่อเนื่องทุกวัน

### บทเรียนและความท้าทาย
- **บทเรียนแบบโต้ตอบ**: เนื้อหาการสอน PowerPoint แบบขั้นตอนพร้อมตัวอย่างจริง
- **ความท้าทายปฏิบัติจริง**: งานที่ต้องทำจริงในโปรแกรม PowerPoint เพื่อพิสูจน์ทักษะ
- **ระดับความยาก**: แบ่งเป็น Beginner, Intermediate, และ Advanced
- **เวลาที่ประมาณการ**: แสดงเวลาที่คาดว่าจะใช้ในการทำแต่ละกิจกรรม

### ระบบผู้ใช้
- **การลงทะเบียนและเข้าสู่ระบบ**: ด้วยอีเมลและรหัสผ่านผ่าน Supabase Auth
- **โปรไฟล์ผู้ใช้**: แสดงข้อมูลส่วนตัว คะแนน เลเวล และความก้าวหน้า
- **การติดตามความก้าวหน้า**: บันทึกการทำบทเรียนและความท้าทายที่เสร็จแล้ว
- **การตั้งค่าส่วนบุคคล**: ปรับแต่งประสบการณ์การใช้งานตามความต้องการ

## เทคโนโลยีที่ใช้

### เฟรมเวิร์กและไลบรารีหลัก
- **React 18**: ไลบรารี JavaScript สำหรับสร้างส่วนติดต่อผู้ใช้
- **Vite 5**: เครื่องมือสร้างและเซิร์ฟเวอร์พัฒนาความเร็วสูง
- **TypeScript**: ภาษาโปรแกรมที่เพิ่มการพิมพ์แบบ static ไปยัง JavaScript
- **Supabase**: แพลตฟอร์มแบ็กเอนด์แบบโอเพ่นซอร์ส (ทางเลือกแทน Firebase)
- **React Router DOM**: สำหรับการนำทางภายในแอปพลิเคชัน

### สไตล์และการออกแบบ
- **Tailwind CSS**: เฟรมเวิร์ก CSS ยูทิลิตี้เฟิร์สต์สำหรับการออกแบบที่รวดเร็ว
- **สีพาสเทลที่กำหนดเอง**: ชุดสีที่ออกแบบมาเพื่อความสบายตาและเหมาะสมกับสภาพแวดล้อมการเรียน

### เครื่องมือพัฒนา
- **ESLint**: เครื่องมือตรวจสอบและแก้ไขโค้ด
- **Prettier**: เครื่องมือจัดรูปแบบโค้ดอัตโนมัติ
- **PostCSS**: เครื่องมือแปลง CSS พร้อมปลั๊กอิน Autoprefixer

## การติดตั้งและการตั้งค่า

### ขั้นตอนที่ 1: คัดลอกโครงการ
```bash
git clone https://github.com/Aszeroo/powerpoint-gamified-app.git
cd powerpoint-gamified-app
```

### ขั้นตอนที่ 2: ตั้งค่าตัวแปรสภาพแวดล้อม
คัดลอกไฟล์ตัวอย่างและตั้งค่าค่าจากโครงการ Supabase ของคุณ:
```bash
cp .env.example .env
```
จากนั้นแก้ไขไฟล์ `.env` เพื่อใส่:
- `VITE_SUPABASE_URL`: URL ของโครงการ Supabase ของคุณ
- `VITE_SUPABASE_ANON_KEY`: คีย์ anon ของโครงการ Supabase ของคุณ

### ขั้นตอนที่ 3: ติดตั้งขึ้นต่อ
```bash
npm install
```

### ขั้นตอนที่ 4: รันเซิร์ฟเวอร์พัฒนา
```bash
npm run dev
```
แอปพลิเคชันจะพร้อมใช้งานที่ `http://localhost:5173`

### ขั้นตอนที่ 5: สร้างเวอร์ชันผลิต
```bash
npm run build
```
ไฟล์ที่สร้างจะอยู่ในโฟลเดอร์ `dist/`

### ขั้นตอนที่ 6: ทดสอบเวอร์ชันผลิต
```bash
npm run preview
```
จะให้บริการที่ `http://localhost:4173`

## การตั้งค่า Supabase

เพื่อให้แอปพลิเคชันทำงานได้อย่างสมบูรณ์ คุณต้องตั้งค่าโครงการ Supabase ดังนี้:

1. สร้างโครงการใหม่ที่ [supabase.com](https://supabase.com)
2. คัดลอก URL และคีย์ anon จากการตั้งค่าโครงการ
3. รันไฟล์ `database_schema.sql` ในส่วน SQL editor ของ Supabase เพื่อสร้างตารางที่จำเป็น:
   - `users`: ข้อมูลผู้ใช้ที่เชื่อมโยงกับ auth.users
   - `user_stats`: สถิติผู้ใช้ (คะแนน เลเวล ความก้าวหน้า ฯลฯ)
   - `tutorials`: ข้อมูลบทเรียน
   - `challenges`: ข้อมูลความท้าทาย
   - `user_challenges` และ `user_tutorials`: ตารางเชื่อมโยงสำหรับความก้าวหน้าของผู้ใช้
4. เปิดใช้งาน Row Level Security (RLS) บนทุกตารางตามที่กำหนดในไฟล์ schema

## คำแนะนำการใช้งานสำหรับครูผู้สอน

### การเตรียมการก่อนเรียน
1. ตั้งค่าโครงการ Supabase ตามขั้นตอนข้างต้น
2. แบ่งปันลิงก์เว็บแอปพลิเคชันให้นักเรียน
3. ให้นักเรียนลงทะเบียนบัญชีด้วยอีเมลของสถาบันการศึกษา
4. กำหนดงานหรือเป้าหมายรายสัปดาห์ (เช่น "ถึงเลเวล 5 ภายในสิ้นสัปดาห์")

### การติดตามความก้าวหน้า
- ใช้กระดานผู้นำในแอปเพื่อสร้างการแข่งขันที่ดีต่อสุขภาพ
- ตรวจสอบสถิติผู้เรียนผ่านหน้าจัดการใน Supabase (หากสร้างขึ้น)
- ให้คำชมเชยเมื่อนักเรียนได้รับแบดจ์หรือเพิ่มเลเวล

### การบูรณาการกับหลักสูตร
- จับคู่บทเรียนในแอปกับหัวข้อที่สอนในชั้นเรียน
- ใช้ความท้าทายเป็นแบบฝึกหัดหรือการบ้าน
- จัดเวลาในชั้นเรียนให้ นักเรียนฝึกปฏิบัติจริงในโปรแกรม PowerPoint
